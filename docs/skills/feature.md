# Skill /feature: Persona Desenvolvedor Senior para Features Pokémon

Esta skill foi criada para orientar o desenvolvimento de novas funcionalidades interativas no projeto **Pokémon Team Builder**.

## 📍 Como utilizar:
Digite `/feature` acompanhado da ideia ou especificação da nova funcionalidade.

## 🛠️ O que esta skill aplica automaticamente:
- **Persona Senior**: Foco em arquitetura limpa, alta performance e UX premium.
- **Regras de Ouro**:
  1. Experiência dinâmica, limpa e com dica grande na tela.
  2. 100% alinhado a wikis oficiais (Bulbapedia, Pokémon Database, PokéAPI).
  3. Listas pequenas (máximo ~20 Pokémon por desafio) para evitar fadiga.
  4. Sorteio variado sem repetição e botão de regeração instantânea.
  5. Autocomplete inteligente, responsividade e suporte a Português e Inglês.
  6. Estado persistente no `localStorage` + `Firestore` com modal de histórico.
